# OFFSHORE

Monorepo for the OFFSHORE intelligent freight forecasting and maritime decision-support platform.

## Repository layout

- `frontend/` — React/Vite dashboard and user interface
- `backend/` — Node.js/Express server
- `geospatial/` — geospatial and maritime processing
- `ml/` — machine-learning and forecasting components
- `database/` — database schemas, migrations, and seeds
- `data/` — shared data resources and data-processing documentation
- `docker/` — container-specific configuration
- `shared/` — shared TypeScript code
- `scripts/` — development and maintenance scripts
- `tests/` — cross-module/integration tests
- `docs/` — project documentation

The ML, geospatial, database, and container subsystems are scaffolded for future implementation; no placeholder implementation code is included.
