# OFFSHORE Frontend

The frontend will provide an interactive Antarctic navigation dashboard.

## Planned screens
- Main navigation dashboard
- Interactive map
- Route planning panel
- Risk map visualization
- Sea-ice forecast panel
- Iceberg trajectory visualization
- Route comparison for fastest, safest and fuel-efficient options
- Alerts and decision explanations

## Planned stack
- React
- TypeScript
- CesiumJS or a 2D geospatial map library
