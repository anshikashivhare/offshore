# Machine Learning Modules

This directory contains the AI components of OFFSHORE.

## Planned modules

### sea_ice_forecasting/
Predict future sea-ice concentration from historical sea-ice and environmental data.

### iceberg_detection/
Detect iceberg candidates in satellite imagery.

### trajectory_prediction/
Predict future iceberg positions using historical trajectories and environmental variables.

Each module should eventually contain:
- data preparation
- model definition
- training scripts
- evaluation scripts
- inference code
