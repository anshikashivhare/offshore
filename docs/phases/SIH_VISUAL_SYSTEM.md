# SIH VISUAL SYSTEM
**Project:** SIH 26059 - Antarctic Navigation

## Tone
The application is a scientific geospatial decision-support prototype. It avoids "startup" aesthetics.
- **NO** glowing neural network webs.
- **NO** fake radar sweeps.
- **NO** arbitrary percentage rings.

## Palette
- **Primary:** Dark Ocean Blue (`#0F172A`)
- **Background:** Deep Slate (`#0B0F19`)
- **Surface:** Mapbox/Deck.gl native cartography.
- **Text:** High-Contrast White (`#F8FAFC`)
- **Muted Text:** Slate Gray (`#94A3B8`)
- **Warning:** Amber (`#F59E0B`)
- **Critical / Blocked:** Crimson (`#DC2626`)
- **Route Emphasis:** Crisp Cyan/Blue (`#0EA5E9`)

## Visual Elements
- **Maps:** Clean, data-heavy, focused on the Antarctic polar region.
- **Route Geometry:** Solid stroke `GeoJSON` lines; no fake pulsating glow.
- **Data Provenance Panels:** Monospace technical typography for versioning strings (e.g. `iceberg_lstm_v002`).
