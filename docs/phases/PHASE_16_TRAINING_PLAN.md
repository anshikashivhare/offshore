**Project:** SIH 26059 - Antarctic Navigation

## 1. Executive Decision
**STATUS: TRAINING_APPROVED**
The dataset, target, features, chronological split strategy, leakage status, and inference compatibility have been explicitly verified. The strict exact inner join proved highly successful, retaining 100% of the limiting target dataset (Sea Ice). Local training on the Mac M5 CPU is approved.

## 2. Processed Dataset Audit
- **Input Rows**:
  - `weather`: 253,200
  - `ocean_currents`: 253,200
  - `sea_ice`: 31,650
- **Aligned Rows**: 31,650
- **Retention**: 100% of the target `sea_ice` dataset was retained.
- **Unmatched Records**: 221,550 `weather` and `currents` rows were discarded. This is expected because they lacked corresponding `sea_ice` observation targets. The resulting dataset is perfectly representative of the target variable.

## 3. Join Integrity
- **Decision:** **EXACT_JOIN_APPROPRIATE**
- **Rationale:** Since 100% of the target variable (`sea_ice`) successfully joined using a strict `[cell_id, timestamp, latitude, longitude]` exact match, there is no scientific justification to introduce temporal or spatial approximation/tolerance (which could introduce interpolation artifacts).

## 4. Target Definition
- **Target Column:** `target_sea_ice_concentration`
- **Physical Meaning:** The expected fractional sea-ice concentration (0.0 to 1.0) for a given geographic cell.
- **Forecast Horizon:** Specified by the `forecast_horizon_hours` input feature.

## 5. Feature Selection
**USE:**
- `latitude`, `longitude`
- `sea_ice_concentration`
- `air_temperature_c`, `sea_surface_temperature_c`, `sea_level_pressure_hpa`
- `wind_speed_m_s`, `wind_direction_deg`, `wind_u_m_s`, `wind_v_m_s`
- `current_speed_m_s`, `current_direction_deg`, `current_u_m_s`, `current_v_m_s`
- `sea_surface_height_anomaly_cm`
- `forecast_horizon_hours`
- Derived Temporal: `month`, `sin_doy`, `cos_doy`

**EXCLUDE (Leakage / Redundant):**
- `target_wind_speed_m_s` (Leakage from weather dataset)
- `data_status`, `data_source_type` (Metadata)

## 7. Temporal Forecasting Design
- **Forecast Lead Time:** Defined explicitly by `forecast_horizon_hours` at prediction time.
- **Leakage Prevention:** `target_sea_ice_concentration` is strictly isolated. No future weather observations are included in historical features.

## 8. Train/Validation/Test Split
- **Strategy:** **Strict Chronological Split**
- **Split Proportions:** 70% Train / 15% Validation / 15% Test
- **Rule:** Do not randomly shuffle the dataset prior to splitting to prevent temporal leakage.

## 9. Spatial Validation
- Spatial representation is maintained since the `sea_ice` grid covers the entire required Antarctic bounds. A random temporal split inherently preserves spatial geometry.

## 10. Distribution Analysis
